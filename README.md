# دفتر ع الفرازة

دفتر الحسابات والمخزن والأوردرات — شغال على Firebase وبيتفتح من أي موبايل.

## الملفات
- `index.html` — الدفتر نفسه.
- `config.js` — إعدادات Firebase (مش سرية).
- `firestore.rules` — قواعد الأمان (متركبة خلاص على Firebase، الملف ده نسخة للرجوع ليها).
- `manifest.json` و `icon-*.png` — عشان يتثبت على الموبايل زي التطبيق.

## الرفع على GitHub Pages
1. الـ repository: Omar-Elkamel/3elfaraza-daftar
2. Settings ← Pages ← Branch: `main` / root ← Save.
3. الدفتر هيبقى على: `https://omar-elkamel.github.io/3elfaraza-daftar/`
4. **مهم:** في Firebase: Authentication ← Settings ← Authorized domains ← Add domain ← `omar-elkamel.github.io`
